# IT Support Labs — Portfolio

Hands-on labs built to practice the full range of what an L1/L2 IT support role touches day to day: Windows and Linux administration, networking and remote troubleshooting, ticketing workflows, and Active Directory — each one documented the way a real ticket or project would be, including what went wrong and how it was resolved, not just a clean walkthrough.

## What Each Lab Covers

**01 — Windows Administration & Virtualization**
Administered a Windows 11 VM end-to-end: local user accounts, NTFS permissions, VM snapshots for safe rollback, Event Viewer log diagnosis, and PowerShell/Task Scheduler automation.

**02 — Linux System Administration**
Administered an Ubuntu VM: user provisioning with password expiry policy, ownership/permission troubleshooting, a Bash backup script with date-stamped folder logic, cron scheduling, and package management via apt.

**03 — Networking & Remote Support**
Configured a router (via TP-Link's official emulator after hardware access wasn't available), diagnosed connectivity with ping/nslookup/ARP, connected via OpenVPN, and established remote access over SSH, RDP, and VNC — three different protocols on the same environment.

**04 — IT Ticketing System**
Set up and ran a cloud-based help desk platform (Spiceworks Cloud Help Desk, after a Docker/virtualization blocker ruled out the originally planned self-hosted option), logged and triaged a ticket through its full lifecycle, documented the resolution, and converted it into a reusable knowledge base article.

**05 — Active Directory Enterprise Lab (Capstone)**
Deployed a Windows Server 2022 Domain Controller, built an OU and security group structure, enforced settings via Group Policy, scripted user provisioning in PowerShell, joined a client to the domain, and resolved three simulated help desk tickets — account lockout, Group Policy troubleshooting, and access/group membership — using the environment built from scratch.
